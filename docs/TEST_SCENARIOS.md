# Сценарии тестирования

Столбцы «Фактический результат» и «Статус» заполняются **после** прогона (Postman Runner / ручной запуск) — приложите скриншоты в отчёт.

| № | Сценарий | Предусловия | Шаги | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|---|---|---|
| T01 | Вход с корректными данными | Админ создан | POST /api/auth/login {username, password} | 200, в ответе token и role=ADMIN | | |
| T02 | Вход с неверным паролем | — | POST /api/auth/login с неверным паролем | 401, сообщение «Неверное имя пользователя или пароль» | | |
| T03 | Доступ без токена | — | GET /api/books без заголовка Authorization | 401 «Требуется аутентификация» | | |
| T04 | Добавление книги | Токен получен | POST /api/books {title, author, isbn, year, totalCopies=3} | 201, availableCopies=3, возвращён id | | |
| T05 | Валидация при добавлении книги | Токен получен | POST /api/books {title:"", totalCopies:-1} | 400, в details перечислены ошибочные поля | | |
| T06 | Дубликат ISBN | Книга из T04 есть | POST /api/books с тем же ISBN | 409, без раскрытия внутренних деталей БД | | |
| T07 | Просмотр списка с сортировкой и пагинацией | ≥3 книги | GET /api/books?sort=title,asc&page=0&size=2 | 200, 2 записи, отсортированы по названию, указаны totalElements/totalPages | | |
| T08 | Поиск по автору без учёта регистра | Книга из T04 есть | GET /api/books?q=ТОЛСТОЙ | 200, в результате книга из T04 | | |
| T09 | Фильтр «только доступные» | Есть книга с availableCopies=0 | GET /api/books?onlyAvailable=true | В результате нет книг с 0 свободных экземпляров | | |
| T10 | Редактирование книги | Книга выдана 1 раз | PUT /api/books/{id} с totalCopies=0 | 409: нельзя уменьшить ниже числа выданных | | |
| T11 | Добавление читателя и проверка email | Токен получен | POST /api/readers с корректными данными, затем с email="abc" | 201; затем 400 с ошибкой в поле email | | |
| T12 | Выдача книги | Книга (3 экз.) и читатель есть | POST /api/loans {bookId, readerId} | 201, dueDate = сегодня + 14 дней, availableCopies=2 | | |
| T13 | Выдача при отсутствии экземпляров | availableCopies=0 | POST /api/loans | 409 «Свободных экземпляров книги нет» | | |
| T14 | Возврат книги | Выдача из T12 | POST /api/loans/{id}/return | 200, status=RETURNED, availableCopies увеличился на 1 | | |
| T15 | Повторный возврат | Выдача из T14 | POST /api/loans/{id}/return | 409 «Книга уже возвращена» | | |
| T16 | Выдача читателю с просрочкой | У читателя просроченная выдача (см. SQL ниже) | POST /api/loans | 409 «есть просроченные книги» | | |
| T17 | Аналитический отчёт | Есть просроченная выдача (SQL ниже) | GET /api/reports/debts | 200; читатель в rows, totalFine = дней × 0.50, итоговые суммы сходятся | | |
| T18 | Удаление книги с историей выдач | Книга имеет запись в loans | DELETE /api/books/{id} под ADMIN | 409 «по ней есть записи о выдаче» | | |
| T19 | Разграничение прав | Вход под LIBRARIAN | DELETE /api/books/{id}; POST /api/auth/register | 403 на обе операции | | |
| T20 | Несуществующий ресурс | — | GET /api/books/999999 | 404 «Книга с id=999999 не найдена» | | |

## SQL для создания просрочки (T16, T17)

```sql
-- id выдачи подставьте свой
UPDATE loans SET issued_at = current_date - 30, due_date = current_date - 16 WHERE id = <id>;
```
