# План работ

| Этап | Что делаем | Результат | Срок |
|---|---|---|---|
| 1. Анализ | Описать предметную область, роли, бизнес-правила | Список требований, ER-диаграмма | 1–2 дня |
| 2. Окружение | Установить JDK 21, Maven, PostgreSQL, Postman, IDE; завести репозиторий | Рабочее окружение | 0.5 дня |
| 3. База данных | Таблицы users, books, readers, loans; ограничения, индексы; миграции Flyway | `V1__init.sql` | 1 день |
| 4. Каркас | Spring Initializr: Web, JPA, Validation, Security, PostgreSQL, Flyway | Запускающееся приложение | 0.5 дня |
| 5. Безопасность | BCrypt, JWT, роли, обработка 401/403 | Авторизация | 1–2 дня |
| 6. CRUD | Книги, читатели: сущности, репозитории, сервисы, контроллеры, валидация | Добавление, просмотр, правка, удаление | 2–3 дня |
| 7. Поиск | Поиск, фильтры, сортировка, пагинация | Поиск и фильтрация | 1 день |
| 8. Выдача/возврат | Транзакции, блокировки, правила (лимиты, просрочка) | Выдача и возврат | 2 дня |
| 9. Отчёт | Отчёт по задолженностям и штрафам | `/api/reports/debts` | 1 день |
| 10. Ошибки | Единый обработчик, коды ответов | `GlobalExceptionHandler` | 0.5 дня |
| 11. Тестирование | Unit-тесты, ≥10 сценариев в Postman, таблица результатов | `TEST_SCENARIOS.md` с заполненными результатами | 2 дня |
| 12. Безопасность и GitHub | Проверка на секреты, `.gitignore`, GitHub Actions (сборка, тесты, сканирование зависимостей), Dependabot, публикация | Проверяемый репозиторий | 0.5 дня |
| 13. Отчёт | 20–30 страниц, скриншоты приложения, Postman и БД | Документ | 3–4 дня |

## Порядок действий
1. БД и миграции → 2. сущности и репозитории → 3. безопасность → 4. CRUD → 5. выдача/возврат → 6. отчёт → 7. тесты → 8. документация.

## Структура отчёта (20–30 страниц)
| Раздел | Страниц | Скриншоты |
|---|---|---|
| Введение: цель, задачи, актуальность | 1–2 | — |
| Анализ предметной области и требований | 2–3 | — |
| Выбор технологий (PostgreSQL, Java, Spring Boot, Postman) | 2–3 | — |
| Проектирование БД (ER-диаграмма, описание таблиц) | 3–4 | таблицы в pgAdmin/DBeaver |
| Архитектура приложения (слои, пакеты, диаграмма) | 2–3 | структура проекта в IDE |
| Реализация: авторизация, CRUD, поиск, выдача, отчёт | 6–8 | запросы и ответы в Postman |
| Безопасность | 2 | ответы 401/403 |
| Обработка ошибок | 1–2 | ответы 400/404/409 |
| Тестирование: таблица сценариев и результаты | 3–4 | запуск `mvn test`, Postman Runner |
| Заключение, список источников, приложения | 1–2 | — |
